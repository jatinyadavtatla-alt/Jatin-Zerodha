# Jatin's Zerodha 🚀

A full-stack trading platform inspired by Zerodha, built using the MERN stack. The project includes a responsive landing page, user authentication, trading dashboard, holdings, positions, orders, funds, and portfolio management.

> ⚠️ This project is created for educational and portfolio purposes and is not affiliated with or endorsed by Zerodha.

---

## 📌 About the Project

Jatin's Zerodha is a full-stack web application that simulates the experience of an online stock trading platform.

The application is divided into three main parts:

- **Frontend** – Landing page and user-facing website
- **Dashboard** – Trading and portfolio management interface
- **Backend** – REST APIs, authentication, database, and business logic
